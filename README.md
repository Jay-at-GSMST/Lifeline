Sometimes finding help is harder than actually asking for it.

LIFELINE is a website I made to help people find resources when they are struggling with things like food, housing, education, jobs, transportation, technology, legal help, or health.

I wanted to make something that could actually be useful to someone. When you're already stressed or dealing with problems, having to search through a bunch of different websites just to figure out where to start can make things even harder. LIFELINE tries to make that process simpler.

What It Does

LIFELINE lets you:

Search for resources
Search by city or ZIP code
Filter resources by category
Use Quick Help buttons
View more information about resources
Visit resource websites

How I Made It

LIFELINE was built using:

HTML
CSS
JavaScript
JSON

The resource information is stored separately in resources.json. JavaScript loads the information and handles the searching and filtering.

Files
index.html — Main website
style.css — Design and layout
script.js — Search and filtering
resources.json — Resource information
Why I Made It

I'm still a high school student, so this project isn't perfect. I'm still learning how to code and build things that people can actually use.

I wanted this project to be more than just another website I made for a coding challenge. I wanted to make something that could potentially help somebody who is having a rough time and doesn't know where to start.

Even if LIFELINE only helps one person find something they needed, then I think making it was worth it.

Important Note

Resource information can change. Contact information, hours, eligibility, costs, and available services should always be checked with the organization before relying on a resource.
Also, it is currently only made for my city, more broad information can be added at a later date after I've done more research.
